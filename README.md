# JROME.WEB

A modern, conversion-focused landing page for JROME.WEB, a web development service focused on helping small businesses, entrepreneurs, and organizations establish a professional online presence.

The website showcases available services, selected projects, pricing, and the development process, while encouraging visitors to request a consultation.

## Features

- Responsive design for desktop, tablet, and mobile
- Modern dark-themed UI with cyan accents
- Hero section with clear calls to action
- Service offerings for business websites, e-commerce, redesigns, and custom web applications
- Portfolio showcase with in-page project previews
- Pricing section with starting prices
- FAQ accordion
- Smooth scrolling navigation
- Built with Next.js and Tailwind CSS

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Purpose

This project serves as the marketing website for JROME.WEB, demonstrating the type of websites and digital experiences available to clients.
